The original range intent survives a code action selecting backticks. The
independent block model supplies exact surrounding source, missing blank-line
padding and literal body (removing exactly one final LF). A symbolic code rule
then admits valid backtick or tilde envelopes. The matcher infers only the
opening/closing spelling, rebuilds the complete expected source and body
selection, and parses the isolated envelope independently as exactly one literal
fence with that exact body. Empty-info ASCII spaces/tabs and legal closing
whitespace remain free; actual nonempty info, mismatched or colliding fences,
extra blocks and changed context fail membership.

A later public input first has to belong to a previously permitted state. It
cannot create an expected value from arbitrary output. The existing continuity
check still compares each full prior output to the next full input. Once an
input binds a permitted spelling, later commands resolve against its actual
source/range. Exact undo/redo stacks retain that chosen spelling, so another
otherwise legal spelling cannot replace it on Redo. The existing driver already
records the required inputs, delivered ranges, outputs and errors; it is unchanged.

Each part has a distinguishing witness: body truncation must fail its original
code step even when repeated as the next input; context and padding corruption
must fail complete reconstruction; width changes alter a later current range;
undo/redo distinguishes exact retained source from the broader allowed family.
Deleting the original-intent check admits caret collapse. Deleting exact source
history admits a different valid fence on Redo. The independent parser rejects
an internal closing collision that delimiter-shape checks alone would accept.
