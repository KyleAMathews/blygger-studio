Parts and jobs:

- Pre-command public value/selection: sampled before setting the next concrete range; bridges the previous full output and supplies actual current/offset geometry.
- Independently resolved effective action/range: driver and checker use source/range intent projection; checks compare the receipt with that projection, so a wrong range cannot be excused by a correct operation on the wrong range.
- Candidate source/selection states: exact ordinary command outcomes; finite sufficient-indent family only where four columns cannot reach the actual parent content.

Input resolution is separately checkable even after a mismatch, and model/check accept partial traces.

## Design revision before executable draft: symbolic raw-prefix family

Independent reviewer rejected an all-space-only extraordinary family because the adopted enough-indent rule leaves correct raw tabs/mixed whitespace free. Parent accepted the correction. Preserve this raw finding; no repository code was changed under the earlier proposal. The revised rule stores a symbolic raw prefix q made only of spaces/tabs, uniform across moved nonblank rows and preceding each row's entire unchanged original raw indentation. Its ending visual column is >=4 and <=20; marker column after q+original level must lie in parent content..content+3. Ordinary exactfour remains exact whenever sufficient. The bound10marker+4effectivepadding+3band+3existing-tab-phase bounds q's ending column independently of q spelling; each raw character advances at least1, so it is finite without enumerating millions of raw spellings. Root independently checked all-space neighbors over11532 input geometries/426684 candidate checks and76585 parser controls, zero failures; general tab-phase proof retained, not a browser verdict.

The checker may infer q from a complete observed output only to validate membership in this predeclared symbolic family: strip exactly the entire known original indent suffix from the first filled output row's leading whitespace, require q's whitespace/column relation, generate the complete expected edit through the independent whole-row model with optional prefix override, and compare the full source and selection. No observation is projected away. The model never reads step outputs. On the next recorded receiving INPUT, the same template matcher binds a valid q and materializes the exact chosen source/history state. A bad previous output repeated in that input still fails at the previous original step. Undo/redo use the retained exact chosen raw source; only undo caret remains unconstrained.

Driver inputN samples BEFORE applying the next range, with an explicitly established initial all-selection. collisionPreInput is captured BEFORE the old EOF reset and must bridge full final-prefix source+selection. Retain focused in step observations diagnostically. Actual reach derives from recorded receiving inputs/resolved action kinds; plan-only canonical construction previews do not count as runtime reach.
