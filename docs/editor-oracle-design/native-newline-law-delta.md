## Design grammar

`newline` names native keyboard insertion; `break` names the Markdown hard-break toolbar command. They are separate model intents. Typing a second prose line distinguishes them: newline inserts LF and produces a soft break; the hard-break command inserts backslash+LF and produces a rendered br. The session model retains document/selection plus native undo/redo snapshots; rendered-break count distinguishes those two continuations when the full editor preview is observed. Synthetic handler calls establish no interception, while the real app key establishes the browser default. A synthetic event cannot prove native insertion.

The minimal adaptation alternatives were (a) change direct keyboard expectations alone, which loses real native-key and hard-break receiving evidence; (b) reinterpret old hard-break histories as soft breaks, which loses adopted command laws; and (c) retain hard-break command histories through the toolbar and add native-newline receiving histories. This change selects (c). No old grammar axis is narrowed.

The legacy session grammar remains a branch with all 43 constructed histories. Four new profiles on each of composer/full/quick edit vary Enter/Shift+Enter, caret/selected replacement, native/refused execCommand, and desktop/mobile; two full-stop end-caret roundtrip histories retain the exact new-main source/continuation and a simulated IPAD case; separate direct key→typing counterparts retain the literal upstream action ordering. The generated newline branch independently varies surface, key, position (caret, selection, end), platform (host/IPAD), native/refusal and viewport. The new ordinary-prose branch starts every word with a letter/emoji and excludes markup-leading punctuation, so either side of a generated split remains prose rather than an ordered list or setext heading; the old grammar keeps every prior string. The nearest invalid histories are command-modified `Control+Shift+Enter`, an unknown position, and a newline rendering body with an unadopted heading marker: the new branch rejects them. Existing modified-Enter classification and focus-view ownership are retained elsewhere, without claiming they insert newlines.

Real native key delivery is recorded after React: key, shift/command/alt modifiers, trusted target, and defaultPrevented=false. The model independently splices exactly LF over the input range and predicts the collapsed caret. Full-editor prose checks paragraph=1/br=0 after both insertion and continuation; composer/quick check source/range/focus. Native undo restores the exact prior source and redo restores the newline. Simulated navigator.platform IPAD is observed when requested; it does not emulate an on-screen keyboard or a physical iPad. Native-undo claims remain absent for forced-refusal histories.
