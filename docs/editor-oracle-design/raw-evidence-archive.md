# Raw editor oracle evidence archive

The 51 historical JSON and JSONL evidence files live on the separate `evidence/editor-oracles-20261122` branch. The immutable snapshot is commit `fb0b79dc0450e5f3d31a5a8f59c0b697b5cc5f6e`.

This archive preserves all 2,297,314 bytes and 54,858 lines. The Markdown design records, reviews and loss audits remain in the main source tree. The oracle runtime does not read these archived files. Runtime fixtures, models, manifests and migration inventories outside this archive stay in the source tree.

The table links to the original file bytes and records each SHA-256. Historical paths and commands in the write-ups refer to that snapshot. Restore the snapshot before running a historical packet's reconstruction commands.

To inspect or restore the archived evidence separately:

```sh
git fetch origin refs/heads/evidence/editor-oracles-20261122
git worktree add --detach /tmp/blygger-oracle-evidence fb0b79dc0450e5f3d31a5a8f59c0b697b5cc5f6e
```

A squash merge keeps the removed evidence out of main's ancestry. A merge commit or rebase merge would retain the earlier evidence commits in that ancestry. Preserve the archive branch when deleting the PR branch.
